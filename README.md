# YKT app pages

個人開発者 `hisashi ogino` の公開アプリ一覧、サポート、プライバシーページを提供するGitHub Pagesリポジトリ。

公開URL: `https://wataraikazui.github.io/ykt-app-pages/`

## 公開前確認

- `index.html` の11本のApp Storeリンク
- 各アプリのサポートページへのリンク
- 「つもつみ」は旧`mitsumori`ページと別物のため、`tsumotsumi/support.html`を使用
- モバイル表示とキーボード操作
- Apple公開アイコンURLの表示
- `robots.txt` と `sitemap.xml`
- 個人開発者のページであり、萩森建設の公式アプリ一覧と誤認させない表記

## 計測

App Store ConnectでWeb用キャンペーンリンクを発行できたら、各`App Storeで見る`リンクへアプリ別のキャンペーントークンを追加する。Provider Token未確認の状態で推測値を入れない。
